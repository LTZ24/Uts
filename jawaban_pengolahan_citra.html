Soal 1

Terdapat sebuah citra grayscale dengan ukuran 200x200 piksel dan 128 derajat keabuan, tentukan ukuran citra tersebut dalam satuan Kbyte!

Jawaban:

Diketahui:

  • Ukuran citra: 200 × 200 piksel
  • Derajat keabuan: 128 = 27 → butuh 7 bit per piksel

Langkah 1 — Hitung total piksel:

Total piksel = 200 × 200 = 40.000 piksel

Langkah 2 — Hitung total bit:

Total bit = 40.000 × 7 = 280.000 bit

Langkah 3 — Konversi ke Byte:

Total byte = 280.000 ÷ 8 = 35.000 byte

Langkah 4 — Konversi ke Kbyte:

Total Kbyte = 35.000 ÷ 1024 ≈ 34,18 Kbyte
Jawaban: ≈ 34,18 Kbyte

Soal 3

Terdapat sebuah citra RGB atau warna, tuliskan coding Python untuk:
a. Menampilkan citra tersebut ke layar!
b. Menambah kecerahan sebanyak 15!
c. Mengubah menjadi citra grayscale!

Jawaban (Kode Python):

import cv2
import numpy as np

# Membaca citra RGB
img = cv2.imread('citra.jpg')

# a. Menampilkan citra ke layar
cv2.imshow('Citra RGB', img)
cv2.waitKey(0)
cv2.destroyAllWindows()

# b. Menambah kecerahan sebanyak 15
brightness = 15
img_bright = np.clip(img.astype(np.int32) + brightness, 0, 255).astype(np.uint8)
cv2.imshow('Citra Cerah +15', img_bright)
cv2.waitKey(0)
cv2.destroyAllWindows()

# c. Mengubah menjadi citra grayscale
img_gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
cv2.imshow('Citra Grayscale', img_gray)
cv2.waitKey(0)
cv2.destroyAllWindows()

Penjelasan:

  • cv2.imread() — membaca file citra ke dalam array NumPy
  • cv2.imshow() — menampilkan citra ke layar
  • np.clip(img + 15, 0, 255) — menambah nilai setiap piksel sebesar 15, dibatasi 0–255
  • cv2.cvtColor(img, COLOR_BGR2GRAY) — konversi RGB ke grayscale menggunakan formula: Y = 0.299R + 0.587G + 0.114B

Nilai intensitas yang mungkin: 0, 1, 2, 3, ..., 15

Rentang nilai: 0 sampai 15 (16 level, menggunakan 4 bit)
